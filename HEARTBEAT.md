# Heartbeat checklist

House rules read at the start of every scheduled automation run. Keep it short. Put a copy in the data
directory (`data/HEARTBEAT.md`) to override this one; delete the text to switch it off.

- Only message me when something has changed since last time.
- If there is nothing new, reply with just NOTHING_TO_REPORT - no summary, no reassurance.
- Don't repeat a finding I've already been told.
